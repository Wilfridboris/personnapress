# PersonnaPress SEO Keyword Opportunity Map

_Research date: 2026-08-15 | Data source: DataForSEO Labs (US / English)_

---

## Executive Summary

PersonnaPress has **zero Google organic rankings** today. All 21 brand mentions are from Capterra/GetApp/SoftwareAdvice directory syndication — no independent editorial coverage. The AI writing category is **structurally declining** (-71% YoY for "ai blog post generator"). The opportunity is not "AI writing" — it's **brand consistency + content automation**, a niche where competition is remarkably thin.

**Core strategic finding:** The keyword "brand voice examples" has 2,900 monthly searches and a keyword difficulty of **2** — near-zero resistance. PersonnaPress's core differentiator (brand voice extraction + consistent multi-platform content) maps perfectly onto a cluster of almost uncontested keywords. Win brand voice first, then expand to the AI content platform category.

**Why the volume is zero:** Developer bloggers on Jekyll/Astro/Hugo are highly technical users who manage their own git workflow. They don't search for "blog publishing tools" — they search for documentation, tutorials, and framework-specific questions. This audience discovers tools through GitHub, Hacker News, dev.to, and word of mouth — not Google commercial searches.

**Recommended strategy (not keyword-driven):**
- The `/github-blog-publishing` landing page (Story 8.6 per epics) is worth building for conversion once users arrive, but organic SEO traffic is not realistic from this page.
- Distribute content on developer platforms instead: dev.to post ("Auto-publish from your AI workflow to Jekyll/Astro/Hugo"), GitHub Marketplace listing, Product Hunt.
- The GitHub App itself appearing in the GitHub Marketplace is a form of distribution that bypasses Google entirely.

| sanity cms alternative | ~100 | ~15 | commercial | Possible comparison target |

**Key finding:** "headless blog API" as a phrase has essentially no search volume — it's a technical concept that hasn't become a searched keyword yet. "headless cms" has volume (4,400 sv) but KD 56 is too competitive for a new domain with zero backlinks. The route "Contentful alternative for blogs" mentioned in the epics is real but low-volume.

**Recommended strategy (AEO-first, not traditional SEO):**
The `/headless-blog-api` page should be optimized for **Answer Engine Optimization** (ChatGPT, Perplexity, Google AI Overviews), not traditional organic ranking. This is exactly what the epics specify: FAQPage schema with at least 5 AEO questions like "What is a headless blog API?" and "How is PersonnaPress different from Contentful?"

Why AEO works here: Developers evaluating headless CMS options increasingly ask AI assistants for recommendations. A well-structured FAQ page with JSON-LD FAQPage schema and accurate technical claims is exactly what AI models cite.

| AEO Target Question | Why It Works |
|---|---|
| What is a headless blog API? | Definitional — AI models answer this by citing authoritative sources |
| Contentful alternative for blogs | Comparison queries have high buyer intent |
| How to deliver blog content via API | How-to queries with code examples get cited |
| What is the difference between headless CMS and traditional CMS? | Informational with high AI citation rate |
| Best headless CMS for developer blogs | Buyer guide format that AI models cite |

**Also target:** Developer-community SEO — submit the API docs to common developer resource aggregators, write a technical post on dev.to or Hashnode titled "Building a Blog with Next.js and a Headless Blog API" (targeting developers who already know Contentful and are looking for simpler alternatives).

## Priority Action Plan

### Phase 1 — Foundation (No-code SEO infrastructure)

These must exist before any content strategy has a chance to work:

1. **SEO metadata per page** — title tags, meta descriptions, OG tags. PersonnaPress currently has none optimized. Every public page (homepage, feature pages, blog) needs proper metadata.
2. **Schema markup** — SoftwareApplication schema on the homepage, BlogPosting schema on blog posts, BreadcrumbList on feature pages.
3. **Sitemap + robots.txt** — Ensure all public pages are crawlable and indexed.
4. **Core Web Vitals** — Next.js 16 with Turbopack should handle this well, but verify LCP and CLS on production.

_Story to build: "SEO Infrastructure — Title Tags, Meta, Schema, Sitemap"_

---

### Phase 2 — Brand Voice Content (Highest ROI content, lowest competition)

1. **Publish "Brand Voice Examples" blog post** — targets KD 2 keyword, 2,900 sv. Drives authority for the brand voice feature page.
2. **Create Brand Voice Feature Page** — targets "brand voice generator" (KD 31). This is where blaze.ai is vulnerable — they're a social scheduler that happens to have brand voice, PersonnaPress is a brand-voice-first content platform.
3. **Publish "What Is Brand Voice" pillar** — builds topical authority cluster.

_Story to build: "Blog Section + Brand Voice Content" or "Brand Voice Landing Page"_

---

### Phase 3 — Platform Positioning (Compete in the AI content platform category)

1. **Homepage copy rewrite** — target "ai powered content creation platform" (6,600 sv, KD 33) and "ai marketing tools" (4,400 sv, KD 19). Current homepage likely doesn't use these phrases.
2. **Integration page** — WordPress + Webflow + LinkedIn + X as trust signals and integration keywords.
3. **"AI Marketing Tools" roundup blog post** — get PersonnaPress listed in its own roundup; builds backlinks when others cite the list.

---

### Phase 4 — Social Proof + Backlinks

The 21 brand citations are all from Capterra/GetApp/SoftwareAdvice — a single directory network. To rank, PersonnaPress needs:
- Independent editorial coverage (Product Hunt launch, indie maker communities)
- Guest posts on marketing/agency blogs
- Being listed in tool roundups ("best AI content platforms", "best brand voice tools")
